# ANA 4315 – Introduction to Bioinformatics

## Project Title
Bioinformatics Programming Assignment

## Introduction
Bioinformatics is an interdisciplinary field that combines biology, computer science, and statistics to analyze biological data such as DNA sequences, proteins, and genomes.

## Assignment Description
This project demonstrates collaborative programming using GitHub. Each group member implemented a script in a different programming language to print their personal details and area of interest in bioinformatics.
